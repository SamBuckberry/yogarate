# Yogarate — Static Single-Page Site + Business Plan (PDF)

## Quick Start

1. Replace `<USERNAME>` and `<REPO>` in HTML `<head>`, `sitemap.xml`, and `robots.txt`.
2. Generate images per prompts in `IMAGE_SPEC.md`. Place 7 images in `/docs/assets/img/`.
3. Push to `main`. GitHub Pages should serve `/docs`.
4. The Business Plan PDF is built by Actions into `/docs/business_plan.pdf`.

## Structure

- **Single-page design**: All content on `index.html` with smooth scroll anchor navigation
- **Legal pages separate**: `privacy.html` and `terms.html` remain standalone for clarity
- **Business plan**: Generated from `content/business_plan.md` via GitHub Actions
